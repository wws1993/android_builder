# 拼图游戏架构文档

## 一、核心定位

- **类型**：异形块拼图（Jigsaw Puzzle）
- **模式**：单机，无网络通信
- **节奏**：无倒计时，可随时暂停/继续

---

## 二、主题与关卡

### 2.1 主题（5 套）

| ID | 名称 | 解锁 | 说明 |
|----|------|------|------|
| 1 | 默认/自然 | 免费 | 自然风景、通用图片 |
| 2 | 动物 | 货币 | 猫狗、野生动物 |
| 3 | 艺术 | 货币 | 名画、插画、抽象 |
| 4 | 城市 | 货币 | 建筑、街景、夜景 |
| 5 | 奇幻 | 货币 | 科幻、幻想风格 |

### 2.2 难度曲线（每主题 10 关）

| 关卡 | 块数 | 规格 |
|------|------|------|
| 1 | 9 | 3×3 |
| 2-3 | 16 | 4×4 |
| 4-5 | 25 | 5×5 |
| 6-7 | 36 | 6×6 |
| 8-9 | 49 | 7×7 |
| 10 | 81 | 9×9 |

**总计**：5 主题 × 10 关 = 50 关

---

## 三、拼图块

- **形状**：矩形，无异形
- **规格**：3×3、4×4、5×5、6×6、7×7、9×9
- **放置**：拖拽到正确格位吸附

---

## 四、货币系统

### 4.1 获取

- 通关奖励（主来源）
- 每日登录（可选）
- 成就奖励（可选）

### 4.2 用途

- 解锁主题 2～5
- 自定义图片替换某一关
- 购买道具

---

## 五、自定义图片

- 玩家选择本地图片替换关卡默认图
- 消耗货币
- 图片存于 localStorage/IndexedDB
- 可恢复默认（消耗少量货币或免费）

---

## 六、历史最佳（Top3）

- 每关记录该玩家多次通关用时
- 保留前 3 名，升序排列
- **展示**：关卡列表显示「最佳 XX 秒」（取第 1 名）
- 无记录时显示「暂无」

---

## 七、道具系统

| 道具 | 效果 |
|------|------|
| 预览 | 短暂显示完整原图 |
| 高亮边缘 | 高亮正确位置轮廓 |
| 自动放置一块 | 随机放置一块正确拼块 |
| 洗牌 | 打乱未完成拼块 |

## 九、界面结构

```
主界面 → 主题选择 → 关卡列表 → 拼图关卡
         ├ 货币显示
         ├ 商店（道具）
         └ 设置
```

关卡列表每关显示：缩略图、最佳 XX 秒、自定义图标识。

## 十、实现说明

### 10.1 文件结构

```
www/
├── index.html          # PixiJS 画布容器
└── assets/
    ├── game.js         # 主入口，全 PixiJS 实现（菜单/主题/关卡/拼图）
    ├── game-config.js  # 主题、关卡、定价
    ├── storage.js      # 本地存档
    └── puzzle-core.js  # 矩形切割（返回 sx,sy,sw,sh）
```

**渲染**：PixiJS v6，通过 CDN 引入。

### 10.2 占位图

无网络或图片加载失败时，使用 `createPlaceholderImage()` 生成 400×400 彩色占位图。

### 10.3 运行

```bash
bun run dev
# 访问 http://localhost:5189
```
